# Zenith Software Crash Detection Frontend

Welcome to Zenith, your go-to solution for software crash detection! This frontend application is designed to provide a user-friendly interface for managing and monitoring crashes in your software.

## Getting Started

Follow these simple steps to get started with Zenith:

1. **Clone the Repository:**
   ```
   git clone https://github.com/your-username/zenith.git
   ```

2. **Navigate to the Project Directory:**
   ```
   cd zenith
   ```

3. **Unzip the Folder:**
   - For Windows users, right-click on the downloaded zip file and select "Extract All."
   - For Linux and macOS users, you can use the following command:
     ```
     unzip zenith.zip
     ```

4. **Run the Application:**
   - Locate the `zenith.exe` (for Windows) or `zenith` (for Linux/macOS) executable file in the extracted folder.
   - Double-click on the executable or use the terminal to run the application.

5. **Explore Zenith:**
   - Once the application is up and running, you can navigate through its intuitive interface to monitor and manage software crashes effectively.

## Features

- **Real-time Crash Monitoring:**
  Keep an eye on your software's health with real-time updates on crashes.

- **Detailed Crash Reports:**
  Access detailed reports for each crash, helping you pinpoint and understand issues quickly.

- **User-Friendly Interface:**
  Zenith offers an intuitive and user-friendly interface, making it easy for both beginners and experienced developers.

- **Customizable Settings:**
  Tailor Zenith to your preferences with customizable settings for notification preferences and crash handling.
